# Демо-сайты (7 шт.) — портфолио одностраничников

Семь готовых демонстрационных сайтов-визиток для экспертов и мастеров из разных
городов России. Каждый сайт — отдельная папка со своими `index.html`, `styles.css`,
`script.js`. Всё на чистом HTML/CSS/JS, без сборки и внешних зависимостей
(картинки — плейсхолдеры picsum.photos, шрифты — Google Fonts).

## Что менять перед продажей

В каждом `index.html` оставлены комментарии на русском, где заменить:
- имя, телефон, e-mail;
- цены в блоке услуг;
- ссылки на соцсети (Telegram/WhatsApp сейчас заглушки `href="#"`, ВК — реальные);
- seed-картинки у `picsum.photos` (или подставить реальные фото клиента);
- тексты отзывов и FAQ.

Формы работают как демо (`alert("Заявка отправлена (демо)")`). Для боевого сайта
подключите отправку (например, Formspree / Telegram-бот / свою почту) или замените
`action="mailto:..."`.

## Локальный запуск

Достаточно открыть `index.html` двойным кликом. Для корректной работы всех фич
(шрифты/запросы) лучше поднять мини-сервер, например:

```bash
# если установлен Python
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой на GitHub Pages

### Вариант A — весь каталог одним сайтом (быстро показать все 7)
1. Залейте папку `demo-sites` в репозиторий (например, в корень или в `/docs`).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch.**
   Выберите ветку `main` и папку `/ (root)` (или `/docs`, если положили туда). Save.
3. Через 1–2 минуты откроется `https://<логин>.github.io/<репозиторий>/` —
   главная витрина со ссылками на все 7 демо.

Пример загрузки через git:
```bash
cd demo-sites
git init
git add .
git commit -m "Демо-сайты: 7 лендингов"
git branch -M main
# создайте пустой репозиторий на GitHub, затем:
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

### Вариант B — каждый клиент получает свой адрес (для продажи)
Заведите по одному репозиторию на каждый сайт (например `site-realtor-ufa`) и
положите файлы этой папки в корень репо. Тогда у каждого будет чистый URL вида
`https://<логин>.github.io/site-realtor-ufa/` — удобно отправлять конкретному
клиенту как «ваш будущий сайт».

## Примечания
- Это именно демонстрация навыков: лёгкие одностраничники, адаптив, анимации при
  скролле, доступность, SEO-теги. Перед продажей адаптируйте контент под клиента.
- Контакты людей найдены через открытый поиск; убедитесь вручную, что своего сайта
  у них нет и профиль живой, прежде чем предлагать.
